A collection of utility scripts and configurations for the Samsung Galaxy S2 (GT-I9100) running postmarketOS.
This setup is strictly headless (no GUI), utilizing only the Linux terminal and fbkeyboard.

​📱 Hardware Target
​Device: Samsung Galaxy S2 (GT-I9100)
​OS: postmarketOS
​Interface: Framebuffer Console (tty1)
​Input: fbkeyboard (Virtual Framebuffer Keyboard)
